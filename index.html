日本で使う前に

日本でこの無線機から電波を出すには、アマチュア無線技士の資格と、アマチュア局の免許の両方が要ります。受信だけの設備は無線局に当たらないので、聞くだけなら免許は要りません（電波法第2条）。

  • 免許：無線局を開くには総務大臣の免許が必要です（電波法第4条）。
  • 技適：取扱説明書にある適合表示は EU・米国（FCC）・カナダ（IC）のもので、日本の技適の記載はありません。実機の本体・電池・箱にも、技適マークはありませんでした（2026 年 11 月 4 日に確認）。技適のない無線機でアマチュア局を開くには、JARD（日本アマチュア無線振興協会）の保証を受けて申請します（くわしくは「資格と免許を取る」）。ただし JARD は、UV-5R Mini の実機から決まりを超える不要な電波（スプリアス）が出たとして、保証できる機種の一覧に載せていません（JARD の資料）。
  • 周波数：この機種は 136〜174MHz と 400〜480MHz で送信できます（miklor）。日本のアマチュアバンドは、このうち 144〜146MHz と 430〜440MHz だけです（JARL バンドプラン）。業務無線や特定小電力などの周波数では送信しないでください。
  • 暗号化：アマチュア無線では、誰でもわかる言葉で通信するよう求められています（東北総合通信局）。メニュー 3-10 Encryption は OFF のまま使います。
  • 警報の送信：メニュー 2-17 Alarm Mode の Send Sound と Send Code は、警報を電波で送ります。免許がないときは On Site（本体だけで鳴らす）にします。
  • 受信した内容：特定の相手あての通信を聞いて、その存在や内容を漏らしたり利用したりすることは禁じられています（電波法第59条）。

防災ラジオとして使う

アマチュア無線の免許がない人が防災ラジオとして使うなら、「FM ラジオをボタン 1 つで聞ける」「電池を長持ちさせる」「うっかり電波を出さない」の 3 つに合わせて設定します。この機種には送信をまとめて止める設定がないので（CHIRP の「Disable TX」は K6 など別の機種向けです）、送信しない工夫がいちばん大切です。

FM ラジオの聞き方

  1. SK1（左側面の下のボタン）を押すと、FM ラジオになります。
  2. [＃] を押すと、放送局を自動で探します。▲▼では少しずつ動きます。
  3. 局が見つからないときは、[EXIT] で受信範囲を切り替えます。
  4. もう一度 SK1 を押すと、ラジオが消えます。

地域の局の周波数は、総務省の一覧で調べられます。紙に書いて本体に貼っておくと安心です。実機では 76MHz から受信できるので、日本の FM 放送の周波数（76.1〜94.9MHz）はすべて受信範囲に入ります。

うっかり送信しないために

  • 左側面の上にある 2 つのボタン（PTT-A・PTT-B）が送信ボタンです。この 2 つは押しません。家族も触るなら、テープを貼って「押さない」と書いておくと確実です。
  • キーロック（[＊] の長押し）をかけても、送信ボタンは使えてしまいます（取扱説明書）。
  • パソコンがあれば、CHIRP で聞くチャンネルを登録するとき Duplex を off にします。そのチャンネルでは、送信ボタンを押しても電波が出ません（「CHIRP の使い方」の節）。

電池と備え

  • 電池がもつ時間：取扱説明書の受信電流 380mA と電池 1600mAh で計算すると、音を出し続けて約 4 時間です。音量を下げると延びます。
  • 充電：満充電でしまい、防災用品を点検するときに充電も確かめます。USB-C ケーブルとモバイルバッテリーを一緒に入れておきます。充電は 5〜40℃ の場所でします（取扱説明書）。
  • ライト：画面の下の真ん中のキーを短く押すと点きます。
  • イヤホン：端子はケンウッド型 2 ピンなので、ふつうの 3.5mm のイヤホンは挿せません。避難所で周りに音を出さずに聞くには、2 ピンのイヤホンが要ります。

資格と免許を取る

日本で電波を出すには、人の資格（アマチュア無線技士）と、局の免許（アマチュア局）の 2 つが要ります。この機種が使う 144MHz 帯と 430MHz 帯なら、いちばんやさしい第四級（4アマ）で足ります。国家試験で資格を取り、電子申請で開局すると、試験と免許の手数料に電波利用料 1 年分を足して約 1 万 1 千円です（無線機の代金は別）。ただし UV-5R Mini は、JARD の測定で決まりを超える不要な電波が出たため、このままでは免許を受けるのが難しい機種です（「この無線機で免許を受けるには」）。

合格したら免許証を申請する

  1. 国家試験に合格したら、総合通信局に無線従事者免許を申請します。手数料は、電子申請（e-Gov）なら 1,750 円、書面なら 2,050 円です（北海道総合通信局）。
  2. 電子申請でも、写真と、免許証を送り返してもらう封筒は郵送します。スマートフォンからは電子申請できません。
  3. 養成課程は、免許証の申請手数料が受講料に入っています。申請のしかたは講習で案内されます。

アマチュア局の免許を受ける（開局）

  1. 技適マークのある無線機を用意します。技適のない無線機は、先に JARD の保証が要ります（次の項）。
  2. 総合通信局に開局を申請します。手数料は、空中線電力 50W 以下なら電子申請 2,750 円、書面 4,530 円です（北海道総合通信局。令和 7 年 10 月 1 日からの額）。
  3. 免許が出ると、コールサインが決まります。2025 年 10 月から免許状はデジタルになり、電子申請なら免許の記録をネットで見られます（東北総合通信局）。
  4. 電波利用料を毎年 300 円払います。免許の有効期間 5 年の分を、まとめて 1,500 円払うこともできます（九州総合通信局、北海道総合通信局）。
  5. 5 年ごとに再免許を申請します（電子申請で 1,700 円）。

この無線機で免許を受けるには

UV-5R Mini には技適がないので、開局の前に JARD（日本アマチュア無線振興協会）の保証を受けます。保証料は、送信機 1 台なら 5,500 円です（JARD 保証料のご案内、2026 年 4 月）。

ただし JARD は、UV-5R Mini の実機を何台か測ったところ、決まりを超える不要な電波（スプリアス）が出たとして、保証できる機種の一覧に載せていません（「保証可能機器リスト」に掲載できなかった機種について）。この機種で保証を受けるには、調整やフィルターで対策してから実機のスプリアスを測り、新しい基準を満たすデータを出す必要があります。測るには専用の測定器と知識が要るので、はじめての人には現実的ではありません。

  • 送信するなら、新しい基準（新スプリアス規格）で技適を受けた無線機を用意するのが近道です。保証は要らず、開局の申請だけで済みます（JARD）。
  • 中古の無線機は、古い基準（旧スプリアス規格）の技適のことがあり、そのときは保証が要ります。本体の技適番号を、総務省の「技術基準適合証明等を受けた機器の検索」で確かめます（JARD の保証可能機器リストの注）。
  • UV-5R Mini は、防災ラジオや、交信を聞いて覚えるための受信用に、そのまま使えます。
  • スプリアスは、目的の周波数の外に出てしまう電波です。業務無線や放送の邪魔になるので、強さの上限が決められています。

免許の前にできること

  • 体験運用：資格がなくても、アマチュア無線家が立ち会えば、その人の局で交信を体験できます。申し込みは要りません。交信の始まりと終わりはアマチュア無線家が行い、体験する人は CQ を出したり、自分から相手を呼んだりはできません。モールス符号の通信もできません（JARL「体験運用ってどんなもの」「体験運用マニュアル」）。
  • 聞いて覚える：145.00MHz や 433.00MHz を聞くと、呼び出しから終わりまでの流れがわかります。流れは「アマチュア無線のしくみ」の節にまとめました。聞いた交信の内容は、人に話しません（電波法第59条）。

アマチュア無線のしくみ

アマチュア無線は、お金のためではなく、無線の技術への興味から行う通信と研究です（東北総合通信局）。この機種でできるのは、VHF と UHF の電波に FM で声を乗せ、交互に話す交信です。

周波数と波長

電波は、とても速く向きが変わる波です。1 秒間に変わる回数を周波数といい、単位は Hz（ヘルツ）です。1MHz は 100 万 Hz なので、145MHz は 1 秒間に 1 億 4500 万回です。

波 1 つ分の長さ（波長）は、300 ÷ 周波数（MHz）で m の単位で出ます。145MHz は約 2m、435MHz は約 70cm なので、144MHz 帯を「2m 帯」、430MHz 帯を「70cm 帯」とも呼びます。

電波の届き方

VHF と UHF の電波は、光のようにほぼまっすぐ進み、山や建物にさえぎられます。届くめやすは、お互いのアンテナから見通せる範囲です。

地球が丸いので、見通せる距離（km）はおよそ 4.12 ×（√ 自分のアンテナの高さ ＋ √ 相手のアンテナの高さ）です（高さは m。Radio horizon、Wikipedia）。地上で手に持ったハンディ機どうし（高さ 1.5m）なら約 10km、高さ 100m の丘の上から地上へは約 46km です。

実際には建物や地形にさえぎられ、これより短くなります。遠くと話すには、高い場所に行く、性能のよいアンテナに替える、レピーターを使うの 3 つが効きます。HF の電波は上空の電離層ではね返って海外まで届きますが、この機種では扱えません。

AM声に合わせて電波の強さを変える受信だけ（エアバンド）

デジタル（D-STAR・C4FM など）声をデータにして送る扱えない

FM には、幅の広い Wide（25kHz）と狭い Narrow（12.5kHz）があります。相手と合っていないと、声が小さく聞こえたり割れたりします。

交互に話すしくみ

  • 単信：1 つの周波数を 2 人で使い、PTT を押している間だけ送信します。送信中は相手の声が聞こえないので、話し終えたら「どうぞ」と言って PTT を放し、相手に渡します。
  • スケルチ：信号がないときの「ザー」という雑音を消す仕組みです。メニュー 2-2 Squelch で強さを決めます。
  • トーン：声と一緒に低い音（CTCSS）や符号（DCS）を送り、それが付いた電波だけを聞いたり、レピーターを動かしたりします。
  • レピーター：山の上などに置かれた中継局です。入力の周波数で受けた電波を出力の周波数で出し直すので、直接届かない相手とも話せます。設定は「レピーターとトーン」の節にあります。

交信の流れ

呼出周波数（144MHz 帯は 145.00MHz、430MHz 帯は 433.00MHz）で相手を見つけ、空いている周波数に移って話すのがふつうの流れです。

  1. 聞く：送信する前に聞いて、ほかの交信の邪魔にならないことを確かめます（無線局運用規則第19条の2）。
  2. 呼ぶ：「CQ、CQ、CQ、こちらは JA1〇〇〇（自分のコールサイン）、どうぞ」のように、相手を決めずに呼びます。決まった相手を呼ぶときは、相手のコールサインを 3 回以下、「こちらは」、自分のコールサインを 3 回以下の順に言います（第20条）。
  3. 移る：応答があったら、空いている周波数を決めて移ります。1 つの周波数をひとりじめしたり、長く占めたりはしません（東北総合通信局）。
  4. 話す：お互いの電波の聞こえ方（RS レポート。「59」がいちばんよい）、名前、運用している場所を伝え合います。話し終えるたびに「どうぞ」と言います。
  5. 名乗る：長い時間送信を続けるときは、10 分ごとを目安に「こちらは」と自分のコールサインを言います（第30条）。
  6. 終わる：「73（セブンティスリー）、さようなら」とあいさつし、最後に自分のコールサインを言います。

守ること

  • 決められたコールサインを使い、名前やあだ名だけで交信しません。
  • 仕事やお金もうけのために使いません。
  • 免許で許された周波数・出力・電波の型式と、バンドプランの区分を守ります。
  • 悪口、わいせつな内容、人のプライバシーにふれる内容は送りません。

この 4 つは、東北総合通信局の「アマチュア無線局の運用ルール」によります。

はじめての操作

箱から出したら、アンテナを付けて充電し、周波数を打って受信するところまでを次の順に進めます。初めて使うときは電池が少なく、低電圧の警告が出ることがあります。

  1. アンテナを右に回して締めます。アンテナを付けずに送信してはいけません。
  2. 電池の背面にある USB-C 端子にケーブルを挿して充電します。ランプが赤なら充電中、緑なら完了です。充電中は電源を切っておきます。USB-C は充電専用で、書き込みには使えません。
  3. 上面のつまみを右に回して電源を入れます。同じつまみで音量を合わせ、左いっぱいに回すと切れます。
  4. 表示が中国語のときは英語にします。[MENU] → [2] → [MENU] → [1] [0] → [MENU] と押し、▲▼で English を選んで [MENU] で決めます（メニュー 2-10 Language）。
  5. [V/M] を押して、画面に VFO を出します（周波数モード）。
  6. 数字キーで周波数を左から打ちます。例：433.000MHz なら [4] [3] [3] [0] [0] [0]。▲▼では、メニュー 2-1 Step の幅で動きます。
  7. 雑音が出るときは、メニュー 2-2 Squelch を LEVEL1〜5 で調整します。雑音が消える一番小さい値にします。
  8. 送信は免許がある場合だけです。PTT-A を押している間は A 段で、PTT-B を押している間は B 段で送信し、ランプが赤くなります。口から 2.5〜5cm 離して話し、放すと受信に戻ります（受信中のランプは緑）。

メニューは [MENU] で開いて▲▼で選び、[MENU] で決めます。[EXIT] を押すと、変更を取り消して出ます。

周波数モードとチャンネルモード

周波数モード（VFO）は周波数を直接打つモード、チャンネルモード（MR）は登録した 999 チャンネルから選ぶモードで、[V/M] で切り替えます。チャンネルは、周波数モードで設定を作ってから登録します。

チャンネルを選ぶ

チャンネルモードで▲▼を押すか、番号を 3 桁で打ちます（64 番なら [0] [6] [4]）。

チャンネルに登録する

  1. 周波数モードで周波数を合わせます。トーン（メニュー 3-6〜3-9）やシフト（3-13・3-14）も、登録の前に設定します。
  2. [MENU] [3] [MENU] [1] [5] と押すと、CH-Memory が選ばれます（取扱説明書では MEMCH）。
  3. [MENU] を押すと CH-001 から番号の一覧が出るので、▲▼でまだ使っていない番号を選んで [MENU] を押します。確認音が鳴れば登録できています。
  4. [EXIT] で待ち受けに戻ります。

名前を付ける・表示を変える

  • 名前：チャンネルモードでメニュー 3-1 CH.NAME を開きます。[＃] で入力方法（英字・数字など）を切り替えます。英字の入力方法では、[1] で記号、[0] で空白が入ります。
  • 表示：メニュー 3-12 CH-MDF で、NAME（名前）・FREQ（周波数）・CH（番号）から選びます。名前を付けても出ないときは NAME にします。

チャンネルを削除する

周波数モードで [MENU] [3] [MENU] [1] [6] と押すと、DELCH と出ます。[MENU] を押し、▲▼で選んで [MENU] で削除します。チャンネル 1 は削除できません。

実機では、周波数モードで 3-15 が CH-Memory でした（2026 年 11 月 4 日に確認）。取扱説明書のメニュー表では 3-16 CH_Memory・3-17 CH_Delete となっています。削除の番号はまだ確かめていないので、合わないときは画面の名前を見て選んでください。

レピーターとトーン

レピーターを使うには、周波数モードでシフトの向きと幅、送信トーンを設定してから、チャンネルに登録します。日本の 430MHz 帯では、レピーターの出力が 439〜440MHz、入力がその 5MHz 下の 434〜435MHz に割り当てられています（JARL バンドプラン）。

  1. [V/M] で周波数モードにし、レピーターの出力周波数（自分が受信する周波数）を打ちます。
  2. メニュー 3-14 Direction で、Minus（送信を低く）か Plus（送信を高く）を選びます。
  3. メニュー 3-13 OffSet で、送信と受信の差（日本の 430MHz 帯なら 5MHz）を入れます。
  4. メニュー 3-8 TX CTCSS で、レピーターが求めるトーンを選びます（日本では多くが 88.5Hz です。各局の案内で確かめてください）。
  5. 「チャンネルに登録する」の手順で登録します。

シフトを設定すると、画面に＋か−が出ます。メニュー 3-13・3-14 は周波数モードのときだけ現れます。

トーンスケルチ（CTCSS・DCS）

メニュー使い方
3-6 RX CTCSS（3-7 RX DCS）そのトーン（コード）が付いた信号だけを聞く。他の信号は鳴らない
3-8 TX CTCSS（3-9 TX DCS）送信にトーン（コード）を付ける。レピーターや相手のスケルチを開けるのに使う

CTCSS は OFF と 67〜254.1Hz、DCS は OFF と 023N〜754I から選びます。受信側にトーンを入れると、相手が同じトーンを出さないかぎり何も聞こえません。

リバース・トークアラウンド・トーンバースト

  • リバース：シフトのある周波数で [＊] を短く押すと、送信と受信の周波数が入れ替わり、R が出ます。相手の電波をレピーターの入力側で直接聞くときに使います。
  • トークアラウンド：[＊] で T にすると、送信も受信周波数で行い、レピーターを通さずに直接話せます。
  • トーンバースト：PTT を押しながら SK1 を押すと、メニュー 2-24 ALERT の音（1000／1450／1750／2100Hz）を送ります。1750Hz で起動する海外のレピーター向けです。

便利な機能

よく使う機能は、キーの長押しか、SK1 への割り当て（メニュー 2-26）で呼び出せます。

スキャン

  • [＃] を長く押すと始まり、もう一度長く押すと止まります。
  • 周波数モードではメニュー 1-1 Freq Ranger の範囲を、チャンネルモードでは登録チャンネルを順に探します。
  • 信号で止まったあとの動きは、メニュー 1-2 Scan Mode で選びます。Time は一定時間で再開、Carrier は信号が消えたら再開、Search は再開しません。
  • スキャンから外したいチャンネルは、メニュー 3-14 SCAN ADD を OFF にします。
  • 周波数モードのスキャンで見つけたトーンの保存先は、メニュー 1-3 Scan Memory で選びます。ALL は送受信の両方（初期値）、DECODER は受信だけ、ENCODER は送信だけです（CHIRP のドライバの説明による。取扱説明書の説明文は、受信と送信が逆に読めます）。

周波数サーチ（相手の周波数を写す）

近くで送信している無線機の周波数とトーンを読み取り、そのままチャンネルに登録できます。

  1. サーチ／ライトキーを長く押します（SK1 に SEARCH を割り当てたときは SK1 を押す）。SEARCH... と出ます。
  2. 相手に送信してもらいます。探す帯域（VHF・UHF など）は [＃] で切り替えます。
  3. 周波数とトーンが出たら、[MENU] で登録します。

読み取れるのは相手の送信周波数とトーンだけで、相手の受信周波数（レピーターのシフトなど）はわかりません（W9LW のレビュー）。

デュアルワッチ

メニュー 2-15 Dual Watch を ON にすると、A 段と B 段の両方を待ち受け、画面に D が出ます。信号が入った段が操作中の段になります。送信する段は、PTT-A・PTT-B のどちらを押すかで選べます。

FM ラジオ

  1. メニュー 2-26 Press SK1 を FM Radio にします。
  2. SK1 を押すと FM ラジオになり、周波数が出ます。
  3. ▲▼で 1 ステップずつ、[＃] で自動選局（SEEK...）します。
  4. [EXIT] で受信範囲を切り替えます。実機でも切り替わることを確かめました（2026 年 11 月 4 日）。取扱説明書には 65.0／75.0MHz とあります。日本の FM 放送（76〜95MHz）が入らないときは、切り替えてみてください。
  5. もう一度 SK1 を押すと戻ります。

ライトとキーロック

  • ライト：サーチ／ライトキーを短く押すと、点灯・消灯します。SK1 に LAMP を割り当てても使えます。
  • キーロック：[＊] を長く押すと錠の絵が出てロックされ、もう一度長く押すと解除されます。
  • 自動ロック：メニュー 2-16 AutoLock を ON にすると、8 秒操作しないとロックされます。解除は [＊] を 2 秒押します。

VOX（声で送信）

PTT を押さずに、話すと送信する機能です。送信するので、免許が要ります。

  • メニュー 2-4 VOX Switch を ON にすると、画面に V が出ます。
  • 感度は 2-5 VOX Level（1〜9、小さいほど敏感）、話し終えてから止まるまでの時間は 2-6 VOX Delay（0.5〜2.0 秒）で決めます。
  • SK1 に VOX を割り当てると、ボタンひとつで切り替えられます。

緊急アラーム

SK1 に SOS を割り当てて押すとアラームが始まり、もう一度押すと止まります。動きはメニュー 2-17 Alarm Mode で選びます。

本体から音を出すかは、2-18 Alarm Tone で決めます。免許がないときは On Site だけを使います。

エアバンドと気象チャンネル

  • エアバンド（108〜136MHz）は、AM で受信だけできます。純正ソフトではチャンネルに書き込めないので、CHIRP を使います（miklor）。この帯域のステップは 8.33kHz になります（CHIRP の報告）。
  • 気象チャンネル：[0] を 3 秒押すと気象モードになり、[＃] を 3 秒押すと 10 チャンネルをスキャンします。米国とカナダの気象放送（NOAA）用で、日本では放送がありません。[PTT] で戻ります。

ストップウォッチ

[MENU] を長く押すと表示され、[MENU] で計測の開始と停止、[EXIT] で終了します。

CHIRP の使い方

CHIRP は、無線機のチャンネルを表のように編集して読み書きできる無料のパソコンソフトです。UV-5R Mini は、2025 年 8 月以降の版でメーカー「Baofeng」、モデル「UV-5R Mini」を選ぶと使えます（CHIRP Issue #12091）。この節では、CHIRP の英語の表示に、日本語の表示を括弧で添えています。

入れる

  1. CHIRP のダウンロードページから、最新の CHIRP-next を入れます。Windows は 10 以降の 64 ビット版が対象です。更新が止まった CHIRP-legacy は使いません。
  2. 版の名前は作られた日付です（例：next-20260123）。新しい版は、CHIRP を閉じてから上書きで入れられます。
  3. 画面を日本語にするには、View → Language...（表示 → 言語...）で日本語を選び、CHIRP を開き直します。訳されていない項目は、英語のまま出ます。

無線機から読み込む

  1. ケーブルのドライバを入れ、Windows のデバイスマネージャーの「ポート（COM と LPT）」で COM 番号を確かめます。
  2. 無線機の右側面の外部端子にケーブルを挿し、電源を入れます。プラグは、かなり強く奥まで押し込みます。浅いと「Radio did not respond as expected」などのエラーになります（CHIRP Issue #12091）。
  3. Radio → Download from radio（無線機 → 無線機からダウンロード）を選びます。
  4. Port（ポート）に COM 番号、Vendor（メーカ）に Baofeng、Model（モデル）に UV-5R Mini を選んで OK を押します。似た名前の UV-5G Mini は米国の GMRS 用で、1〜30 チャンネルの周波数を変えられないので選びません（CHIRP のドライバ）。
  5. 読み込んだら、すぐに File → Save As（名前を付けて保存）で .img ファイルに保存します。これが、元に戻すときの控えになります。

CSV を作る

  1. メモ帳を開き、上の例をそのまま貼ります。
  2. 「ファイル」→「名前を付けて保存」を選びます。
  3. 「ファイルの種類」を「すべてのファイル (*.*)」にし、名前を bousai.csv のように .csv で終わらせて保存します。「テキスト ドキュメント」のままだと、名前の最後に .txt が付いて CHIRP で開けないことがあります。
  4. 文字コードは UTF-8 のままで大丈夫です。

CSV のチャンネルを貼り付ける

  1. 「無線機から読み込む」の手順で無線機の中身を読み込み、.img に保存しておきます。
  2. File → Open（ファイル → 開く）で CSV を開きます。画面の上に、CSV のタブが増えます。
  3. CSV のタブで、左端の番号「1」をクリックし、Shift キーを押しながら最後の番号（例では「4」）をクリックします。全部を選ぶ操作（Ctrl+A）は使いません。空の行まで選ばれて、貼り付けた先のチャンネルを消してしまいます。
  4. Ctrl+C でコピーします。右クリック → Copy（コピー）でも同じです。
  5. 上のタブで無線機の表に戻ります。周波数が空の行の左端の番号をクリックし、Ctrl+V で貼り付けます。右クリック → Paste（ペースト）でも同じです。
  6. 「Overwrite memories?（メモリを上書きしますか？）」と出たら、貼り付け先にもう使っている行があります。No（いいえ）を押して、空いている行を選び直します。
  7. 貼り付けたら、次の「書き込む」の手順で無線機に書き込みます。

File → Import from file（ファイルからインポート）でも入れられます。ただし、CSV にある番号の範囲（例なら 1〜4 番）を、無線機の同じ番号に上書きします。上書きの前に確認は出ますが、入っているチャンネルを消すおそれがあるので、CHIRP 自身も「開いてコピーする」方法を勧めています（wxui/main.py、wxui/memedit.py）。

書き込む

  1. 表を直したら、Radio → Upload to radio（無線機 → 無線機にアップロード）を選びます。
  2. 読み込みのときと同じポート・メーカ・モデルで OK を押します。
  3. 終わったら、無線機の画面でチャンネルを確かめます。

左の一覧の Settings（設定）では、本体の設定も変えられます。Basic Settings には TOT、バックライト、ROGER、省電力、アラーム、Bluetooth などがあり、DTMF Encode Settings には DTMF のコードがあります。変えた設定も、Upload to radio で書き込みます。
